# CalendarIndexView.vue 前端文件接口文档

## 文档说明

本文档用于前端 `CalendarIndexView.vue`（日历首页）与后端接口的对接，明确前端的接口调用方式、参数格式、响应格式及核心业务逻辑，便于后端开发对应接口。

## 基础信息

- 前端技术栈：Vue3 + Element Plus + axios 1.14
- axios 基础路径：`http://localhost:8080/api`（后端需保证该域名/端口可访问，或协商修改）
- 数据交互格式：JSON
- 统一响应格式：
  
  ```json
  {
    "code": 200, // 状态码：200=成功，500=服务器错误，400=参数错误等
    "msg": "操作成功", // 提示信息
    "data": {} // 业务数据（可选，根据接口返回）
  }
  ```

## 核心业务逻辑

1. **当日事件**：与日历选中日期绑定，切换日期时重新请求对应日期的事件；删除时仅需事件ID，后端通过ID关联日期。
2. **备忘录**：独立存储，不绑定日期，请求/删除均不携带日期参数。

## 接口详情

### 1. 获取当日事件

- **接口用途**：根据选中日期查询该日期的所有事件
- **请求方式**：GET
- **接口路径**：`/daily-events`
- **请求参数（Query）**：

  | 参数名 | 类型   | 必填 | 说明                | 示例值      |
  |--------|--------|------|---------------------|-------------|
  | date   | String | 是   | 日期（YYYY-MM-DD）| 2026-04-08 |

- **响应示例（成功）**：

  ```json
  {
    "code": 200,
    "msg": "查询成功",
    "data": [
      {
        "id": 1,          // 事件ID（后端自增/唯一标识）
        "content": "上午9点开项目会议", // 事件内容
        "date": "2026-04-08" // 事件绑定日期
      },
      {
        "id": 2,
        "content": "下午3点提交周报",
        "date": "2026-04-08"
      }
    ]
  }
  ```

- **响应示例（失败）**：

  ```json
  {
    "code": 500,
    "msg": "查询当日事件失败",
    "data": null
  }
  ```

### 2. 删除当日事件

- **接口用途**：根据事件ID删除指定的当日事件
- **请求方式**：DELETE
- **接口路径**：`/daily-events/{id}`（{id}为事件ID，路径参数）
- **请求参数**：无（ID已包含在路径中）
- **响应示例（成功）**：

  ```json
  {
    "code": 200,
    "msg": "事件删除成功",
    "data": null
  }
  ```

- **响应示例（失败）**：

  ```json
  {
    "code": 500,
    "msg": "事件不存在或删除失败",
    "data": null
  }
  ```

### 3. 获取所有备忘录

- **接口用途**：查询所有独立存储的备忘录（无日期限制）
- **请求方式**：GET
- **接口路径**：`/memos`
- **请求参数**：无
- **响应示例（成功）**：

  ```json
  {
    "code": 200,
    "msg": "查询成功",
    "data": [
      {
        "id": 1,          // 备忘录ID（后端自增/唯一标识）
        "content": "买牛奶和面包" // 备忘录内容
      },
      {
        "id": 2,
        "content": "周末整理桌面"
      }
    ]
  }
  ```

- **响应示例（失败）**：

  ```json
  {
    "code": 500,
    "msg": "查询备忘录失败",
    "data": null
  }
  ```

### 4. 删除备忘录

- **接口用途**：根据备忘录ID删除指定的备忘录
- **请求方式**：DELETE
- **接口路径**：`/memos/{id}`（{id}为备忘录ID，路径参数）
- **请求参数**：无（ID已包含在路径中）
- **响应示例（成功）**：

  ```json
  {
    "code": 200,
    "msg": "备忘录删除成功",
    "data": null
  }
  ```

- **响应示例（失败）**：

  ```json
  {
    "code": 500,
    "msg": "备忘录不存在或删除失败",
    "data": null
  }
  ```

## 前端页面交互逻辑（便于后端理解调用时机）

1. **页面初始化**：
   - 前端默认选中当前日期（格式：YYYY-MM-DD）；
   - 立即调用「获取当日事件」接口（携带默认日期）；
   - 立即调用「获取所有备忘录」接口。
2. **日期切换**：
   - 用户选择新日期后，触发「获取当日事件」接口（携带新日期），更新当日事件列表。
3. **删除操作**：
   - 点击「删除」按钮，调用对应删除接口；
   - 接口返回成功后，前端直接过滤列表数据（无需重新请求）；
   - 接口返回失败时，前端弹出错误提示（如“删除失败，请重试”）。

## 后端数据库设计建议

### 当日事件表（示例表名：daily_events）

| 字段名    | 类型         | 说明                  |
|-----------|--------------|-----------------------|
| id        | BIGINT       | 主键（自增）|
| content   | VARCHAR(500) | 事件内容              |
| date      | DATE         | 事件绑定日期          |
| create_time | DATETIME    | 创建时间（默认当前）|

### 备忘录表（示例表名：memos）

| 字段名    | 类型         | 说明                  |
|-----------|--------------|-----------------------|
| id        | BIGINT       | 主键（自增）|
| content   | VARCHAR(500) | 备忘录内容            |
| create_time | DATETIME    | 创建时间（默认当前）|

## 注意事项

1. 日期格式统一使用 `YYYY-MM-DD`，避免时区/格式不一致导致的查询错误；
2. 接口返回的 `code` 字段需严格遵循约定（200为成功），前端根据 `code` 判断是否处理数据；
3. 若后端需要调整接口路径/参数格式，需提前与前端协商，避免对接失败；
4. 接口需处理空数据场景（如无当日事件时，`data` 返回空数组 `[]`，而非 `null`）。
