# 时间管理系统 — 设计文档

## 1. 设计理念

**定位**：个人时间管理与专注辅助工具，支持多用户注册。

**设计原则**：
- 简洁直观的卡片式布局，信息一目了然
- 毛玻璃 + 半透明背景，可自定义背景图，营造沉浸式体验
- 流畅的微交互动画（悬停下沉、点击缩放、标签呼吸）
- 中国本地化（中文界面、中国节假日、农历信息）

## 2. 页面设计

```

│                                     │
│          ┌───────────────┐          │
│          │  时间管理系统  │          │
│          │               │          │
│          │ [ 登录 | 注册 ]│   ← 选项卡
│          │               │          │
│          │  账号: [    ] │          │
│          │  密码: [    ] │          │
│          │  (确认密码)   │   ← 注册模式
│          │               │          │
│          │  [  登 录  ]  │          │
│          └───────────────┘          │
```

**特性**：
- 登录/注册双选项卡切换

## 3. 视觉设计系统

### 3.1 颜色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主题色 | `#409eff` | Element Plus 蓝色系 |
| 导航栏 | `rgba(44,62,80,0.92)` | 深蓝灰半透明 + 毛玻璃 |
| 卡片背景 | `rgba(255,255,255,0.72)` | 半透明白 + 模糊 |
| 专注渐变 | `#667eea → #764ba2` | 紫色渐变（按钮、柱状图） |
| 积分渐变 | `#f093fb → #f5576c` | 粉红渐变 |
| 完成/过期 | `rgba(180,180,180,0.3)` | 深灰半透明 + 删除线 |

### 3.2 标签颜色

| 标签 | 背景色 | 文字色 |
|------|--------|--------|
| 生活 | `#e8f5e9` | `#2e7d32` |
| 学习 | `#e3f2fd` | `#1565c0` |
| 工作 | `#fff3e0` | `#e65100` |
| 娱乐 | `#fce4ec` | `#c62828` |
| 社交 | `#f3e5f5` | `#7b1fa2` |

### 3.3 动效规格

| 交互 | 动画 | 时长 |
|------|------|------|
| 卡片悬停 | `translateY(-1px)` + 阴影增强 | 0.2s |
| 按钮点击 | `scale(0.97)` 按压感 | 0.2s |
| 标签悬停 | `scale(1.08)` 放大 | 0.15s |
| 考试倒计时 | `opacity` 脉冲呼吸 | 2s 循环 |
| 柱状图 | `width` 过渡展开 | 0.5s |
| 备忘录条目 | `translateY(-1px)` 下沉 | 0.15s |

### 3.4 圆角规范

| 组件 | 圆角值 |
|------|--------|
| 卡片 | 16px |
| 按钮 | 10px |
| 输入框 | 10px |
| 对话框 | 16px |
| 搜索栏 | 20px (药丸形) |
| 标签 | 10px |
| 快捷添加输入框 | 19px |
| 快速添加按钮 | 20px (圆形) |
| 表格 | 12px |

## 5. 用户体验流程

```
未登录 → /login → 注册 or 登录
                      ↓
                  登录成功 (存储 isLogin, username, role)
                      ↓
              ┌───────┴────────┐
              ↓                ↓
          普通用户          管理员(admin)
          (无用户管理)      (可见用户管理)
              ↓                ↓
     ┌───────┼───────┐      同上 + /user/information
     ↓       ↓       ↓
  日历页  事件总览  专注模式
  (主界面) (今日时间轴) (计时+排行)
     ↓       ↓       ↓
  添加备忘录 添加事件  全屏专注
  (快捷栏)  (对话框)  (计时器)
```
