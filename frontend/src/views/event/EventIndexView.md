# EventIndexView.vue 前端接口设计文档
> 📌 **页面用途**：这是「**添加备忘录**」页面的前端设计文档，用于规范前端与后端的接口交互逻辑、数据格式及数据库设计，助力后端快速对接开发。

---

## 1. 基础信息
| 项目 | 内容 |
| :--- | :--- |
| **组件文件名** | `EventIndexView.vue`（核心功能：添加独立备忘录） |
| **前端技术栈** | Vue3 + Element Plus + Axios 1.14 |
| **核心功能** | 1. 输入备忘录内容；2. 提交至后端保存（无日期绑定）；3. 表单重置 |
| **所属模块** | 备忘录管理模块（Memo） |
| **依赖组件** | `ContentField.vue`（公共卡片容器，保持系统风格统一） |
| **核心差异** | 备忘录独立存储，不与任何日期绑定，仅需保存内容 |

---

## 2. 前端页面布局与交互
### 2.1 页面结构
页面为单表单布局，元素垂直排列（无日期选择框）：
1. **页面标题**：添加备忘录
2. **备忘录内容输入框**：多行文本框，支持输入长文本
3. **提交按钮**：触发添加操作
4. **重置按钮**：清空输入框内容

### 2.2 交互流程
1. **页面加载**：表单为空，输入框显示占位提示（如“请输入备忘录内容”）；
2. **输入内容**：用户在文本框填写备忘录内容（如“买牛奶、整理桌面”）；
3. **点击添加**：
   - 前端先校验“内容非空+长度≤500字”；
   - 校验通过后调用后端新增接口；
   - 后端返回成功 → 前端提示“添加成功”并清空表单；
   - 后端返回失败 → 前端提示后端返回的错误信息；
4. **点击重置**：清空输入框，重置表单校验状态。

## 3. 后端接口约定（核心）
### 3.1 接口基础规范
- **基础路径**：`/api`（与前端 Axios 配置一致）；
- **数据交互格式**：JSON；
- **统一响应格式**（所有接口遵循）：
  ```json
  {
    "code": 200,   // 200=成功，400=参数错误，500=服务器错误
    "msg": "操作成功", // 提示信息，前端直接展示
    "data": null   // 业务数据（新增接口无返回数据）
  }
  ```

### 3.2 新增备忘录接口
#### 3.2.1 接口核心信息
| 项 | 内容 |
| :--- | :--- |
| **接口名称** | createMemo |
| **请求方式** | POST |
| **接口路径** | `/memos` |
| **功能描述** | 将用户输入的备忘录内容保存到数据库，无日期关联 |

#### 3.2.2 请求参数（Body 体）
| 参数名 | 类型 | 必填 | 说明 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| `content` | String | 是 | 备忘录内容，长度限制 1~500 字符 | "周末整理电脑文件、购买水果" |

**请求示例**：
```json
{
  "content": "每天晚上8点运动30分钟"
}
```

#### 3.2.3 响应结果
**成功响应**（HTTP 200）：
```json
{
  "code": 200,
  "msg": "备忘录添加成功",
  "data": null
}
```

**失败响应**（HTTP 400/500）：
```json
// 参数错误（如内容为空/超长）
{
  "code": 400,
  "msg": "备忘录内容不能为空且长度不超过500字",
  "data": null
}

// 服务器错误
{
  "code": 500,
  "msg": "服务器异常，添加失败",
  "data": null
}
```

## 4. 数据库设计（后端实现参考）
### 4.1 数据表名
`memos`（备忘录表，独立于日期事件表）

### 4.2 表结构设计
| 字段名 | 数据类型 | 主键 | 非空 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | BIGINT | ✅ | ✅ | 自增主键，备忘录唯一标识 |
| `content` | VARCHAR(500) | ❌ | ✅ | 备忘录内容（限制500字符） |
| `create_time` | DATETIME | ❌ | ✅ | 创建时间，默认当前时间（无需前端传参） |

### 4.3 示例数据
| id | content | create_time |
| :--- | :--- | :--- |
| 1 | 买牛奶和面包 | 2026-04-08 10:15:00 |
| 2 | 复习Vue3组合式API | 2026-04-08 14:20:00 |

## 5. 前端校验规则（后端需兼容）
为减少无效请求，前端已做前置校验，后端建议同步校验：
1. **`content` 非空**：禁止提交空字符串/全空格内容；
2. **`content` 长度限制**：1 ≤ 字符数 ≤ 500；
3. **字符编码**：支持中文/英文/数字/符号，后端需用 UTF-8 存储。

---

## 6. 错误处理规范
### 6.1 前端提示逻辑
| 场景 | 前端提示信息 | 后端适配建议 |
| :--- | :--- | :--- |
| 内容为空 | “请输入备忘录内容” | 接口返回 code=400，msg=“内容不能为空” |
| 内容超长 | “备忘录内容不能超过500个字” | 接口返回 code=400，msg=“内容长度超过限制” |
| 网络异常 | “网络异常，请稍后重试” | 无需处理（前端本地提示） |
| 服务器错误 | “服务器异常，请联系管理员” | 接口返回 code=500，msg=具体错误原因 |

### 6.2 后端错误码映射
| 前端场景 | 后端返回 code | 说明 |
| :--- | :--- | :--- |
| 操作成功 | 200 | 通用成功码 |
| 参数错误 | 400 | 内容为空/超长/格式错误 |
| 服务器内部错误 | 500 | 数据库异常/代码报错等 |

## 7. 关联接口（备忘录模块闭环）
| 页面/功能 | 接口路径 | 请求方式 | 功能描述 |
| :--- | :--- | :--- | :--- |
| 日历页面-查询备忘录 | `/memos` | GET | 查询所有备忘录列表 |
| 日历页面-删除备忘录 | `/memos/{id}` | DELETE | 根据ID删除指定备忘录 |
| 本页面-新增备忘录 | `/memos` | POST | 添加新备忘录 |

---

## 8. 注意事项
1. **无日期绑定**：备忘录表无需 `date` 字段，与 `daily_events`（当日事件表）严格区分；
2. **接口一致性**：新增/查询/删除备忘录的接口路径均以 `/memos` 开头，便于后端路由统一管理；
3. **数据唯一性**：`id` 字段必须设为自增主键，确保每条备忘录唯一；
4. **兼容性**：前端请求参数仅 `content`，后端请勿要求额外参数（如 `date`），避免对接失败。

> 🎯 本文档与 `CalendarIndexView.vue`（日历页面）、`MemorandumIndexView.vue`（添加当日事件）配套，确保备忘录模块“新增-查询-删除”功能闭环。
